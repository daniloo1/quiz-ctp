=========================================
✈️ SITO & SIMULATORE QUIZ AVES
=========================================

Apri index.html con Safari, Chrome o un browser moderno. Il sito funziona anche offline.

FUNZIONI
- Dashboard con riepilogo sessioni, media e copertura delle domande.
- Simulazione con scelta della materia, modalità di ripasso (Allenamento, Esame e Lettura rapida), timer e correzione.
- Funzione Lettura / Banca Dati: consultazione immediata di tutte le domande (Domanda - Risposta Corretta) con ricerca istantanea e filtri.
- Storico, analisi degli errori e ripetizione delle domande sbagliate.
- Note personali e segnalibri associati alle singole domande, con elenco paginato.
- Modalità chiara/scura.
- Esportazione delle note personali in JSON.

DATI E PRIVACY
Le domande sono incluse nel sito e non vengono modificate dalle funzioni personali.
Statistiche, tema, dimensione del testo, note e segnalibri sono salvati localmente nel browser.
L'esportazione crea una copia JSON delle note e dei segnalibri.

FILE
- index.html: applicazione web completa.
- quiz_data.json: banca dati delle domande in formato JSON.
- Anki_Banca_Dati_AVES.txt: file per l'importazione in Anki.
- generate_quiz_html.py: aggiorna in index.html solo la banca dati incorporata, preservando l'interfaccia.
